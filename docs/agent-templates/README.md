# 预置助手模板

本目录包含 23 个 AI 实用小助手模板，覆盖多种 AI 设计场景。

## 使用方式

管理员部署后，通过系统设置的 "数据导入" 功能导入 `agent-templates.json` 文件即可。

## 助手清单

| 5   | 翻译助手         | 文本生成 | 中英日韩多语言互译                           |
| 6   | 数据分析助手     | 文本生成 | 数据解读、图表描述、统计分析                 |
| 7   | 海报设计助手     | 图像生成 | 生成海报概念图和设计草图                     |
| 8   | 产品概念图助手   | 图像生成 | 工业设计概念图和产品渲染                     |
