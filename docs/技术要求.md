# 技术要求

## 一、技术的内容、形式和要求

该平台支持通过调用外部服务商 API 接口，实现以下技术功能（相关 API 账户由甲方管理，API 实际发生费用由甲方承担）：

1. **文生文**
   - 平台需要能够接收和回复文字信息。
2. **文生图**
   - 支持输入文字生成图片。
3. **文生视频**
   - 支持根据提示词生成对应要求的视频。
   - 联网情况下调用 API，离线情况下使用本地部署大模型。
4. **图生图**
   - 支持根据提示词和参考图生成对应要求的图片。
   - 联网情况下调用 API，离线情况下使用本地部署大模型。
5. **图生视频**
   - 支持根据提示词和参考图生成对应要求的视频。
   - 联网情况下调用 API，离线情况下使用本地部署大模型。
6. **视频生视频**
   - 支持根据提示词和参考视频生成对应要求的视频。
   - 联网情况下调用 API，离线情况下使用本地部署大模型。
7. **图意理解**
   - 支持输入图片并理解图片内容。
8. **语音交互**
   - 支持语音输入，AI 生成语音后输出。
9. **账号管理**
   - 支持账号注册、多用户账号登录、角色管理、用户分组。
10. **用户层级管理**

- 支持独立会话历史管理。
- 管理用户可以查看其管辖下的所有用户话题。
- 同组用户可查看本组全部话题，且话题访问过程中针对当前访问用户锁定。

11. **多助手切换**

- 支持自定义人设助手，并支持切换。

12. **知识库管理**

- 支持上传指定格式文件到知识库，并进行智能回复。

13. **部署要求**

- 平台部署在甲方服务器。

以上平台系统的具体功能模块及对应价格清单，将在**附件 1**中展示。

## 二、附件 1：AI 多模态交互平台系统功能分拆报价

### 1. 基础架构

- **功能描述**
  - 提供整个平台功能的基础框架。
- **重要功能指标**
  - 深度集成多个离线大模型，支持文本、图像、语音、视频多模态交互。
  - 兼容主流大语言模型接口标准，已完成 DeepSeek、豆包等模型在线原生 API 集成与优化。
  - 前端支持主流富文本格式解析展示，包括 Markdown、代码块高亮、表格、列表等。
  - 具备 NSFW 实时检测功能，过滤违规内容。
  - 支持对话会话中底层大模型零中断动态切换。
  - 可展示模型思维链（CoT）中间思考步骤与逻辑推导过程。
- **备注**
  - 需要甲方提供 API。
  - 能够调用大模型进行文字回复。

### 2. 多用户管理

- **功能描述**
  - 支持多用户、账号体系、角色管理、用户分组。
- **重要功能指标**
  - 提供多源身份验证（邮箱验证 + token 密钥机制）与安全接入。
  - 实现基于角色的精细化权限访问控制（RBAC），区分普通用户与企业管理员，遵循最小权限原则与数据隔离。
  - 管理员可对单用户知识库文件容量、向量数据库向量存储数量设置阈值上限。
- **备注**
  - 无。

### 3. 集成视觉识别

- **功能描述**
  - 能够在聊天中发送图片，大模型可以基于理解的图片内容进行回复。
- **重要功能指标**
  - 支持本地文件上传或拖拽主流格式图像。
  - 可调用内置 AI 图像生成 API，将文本转化为视觉草图作为输入。
  - 具备图像理解能力，可基于图像内容进行多模态交互回复。
- **备注**
  - 需要甲方提供 API。

### 4. 用户层级管理

- **功能描述**
  - 管理用户可以查看其管辖下的所有用户话题。
  - 同组用户可查看本组全部话题，话题访问中针对当前访问用户锁定。
- **重要功能指标**
  - 支持多会话管理，可围绕同一助手创建多个独立对话会话，实现并行工作与任务隔离。
  - 支持会话标题与内容全文检索，可按时间维度自动或手动归档历史会话。
  - 提供历史会话永久删除功能，保障数据隐私。
  - 支持自定义上下文窗口，可设置助手推理时考虑的历史消息条目上限（0-20）。
- **备注**
  - 无。

### 5. TTS

- **功能描述**
  - 生成的文字回复可以转成语音播放，支持定制音色功能。
- **重要功能指标**
  - 无缝接入并动态切换多种第三方或自研 TTS 合成服务接口。
  - 提供可视化声纹库，支持选择不同性别、音色、语言风格的语音模型声源，且可实时试听。
  - 离线状态下支持男声、女声两个语音声源。
- **备注**
  - 需要甲方提供 API。

### 6. STT

- **功能描述**
  - 支持用户通过语音输入。
- **重要功能指标**
  - 集成高精度实时语音转文本（ASR）能力，麦克风语音输入实现低延迟、高精度实时转写。
- **备注**
  - 需要甲方提供 API。

### 7. 文生图

- **功能描述**
  - 支持文生图功能接入。
- **重要功能指标**
  - 离线环境下完整支持文生图能力，不依赖公网接口与外部云服务。
  - 支持对提示词进行结构化引导与反复调整，以优化生成效果。
  - 最高可生成 2K 分辨率静态图像，满足课程展示、海报草图、产品概念图等场景需求。
- **备注**
  - 需要甲方提供 API。

### 8. 私有知识库

- **功能描述**
  - 可以根据本地知识库内容进行智能回复，并支持自行管理知识库。
- **重要功能指标**
  - 搭建企业级私有化知识检索增强（RAG）体系，并与平台物理隔离，保障数据安全与专属性。
  - 支持结构化、非结构化异构数据源处理，将各类数据转化为统一向量表示后存储。
  - 允许创建自定义多层级文件夹结构，组织分类知识资产。
  - 支持基于文件名、上传时间等元数据与文件内容关键字的联合检索。
  - 支持批量拖拽或选择上传文件夹，并自动保持原始目录层级结构。
- **备注**
  - 无。

### 9. 文生视频

- **功能描述**
  - 支持根据提示词生成对应要求的视频。
  - 联网情况下调用 API，离线情况下使用本地部署大模型。
- **重要功能指标**
  - 离线环境下支持文生视频能力，不依赖公网接口，基于本地或私有化服务器算力。
  - 可结合镜头语言要素（景别、镜头运动、光影、色调）生成动态内容。
  - 最高生成 720P 分辨率、最长 5 秒的动态视频。
  - 支持通过提示词微调，实现画面节奏、视觉重点、情绪表达的优化。
- **备注**
  - 需要甲方提供 API。

### 10. 图生图

- **功能描述**
  - 支持根据提示词和参考图生成对应要求的图片。
  - 联网情况下调用 API，离线情况下使用本地部署大模型。
- **重要功能指标**
  - 离线环境下支持图生图能力，基于参考图 + 文本提示词生成定制化图片。
  - 支持对参考图的元素、风格、构图、色调进行个性化调整生成。
- **备注**
  - 需要甲方提供 API。

### 11. 图生视频

- **功能描述**
  - 支持根据提示词和参考图生成对应要求的视频。
  - 联网情况下调用 API，离线情况下使用本地部署大模型。
- **重要功能指标**
  - 离线环境下支持图生视频能力，将静态图像转化为叙事性动态视频，不依赖公网接口。
  - 可通过提示词补充画面运动逻辑、光影变化、镜头切换、氛围基调等要求。
  - 最高生成 720P 分辨率、最长 5 秒的动态视频。
  - 支持调整运动速度、画面过渡、特效添加等细节，实现视觉元素动态延伸。
- **备注**
  - 需要甲方提供 API。

### 12. 视频生视频

- **功能描述**
  - 支持根据提示词和参考视频生成对应要求的视频。
  - 联网情况下调用 API，离线情况下使用本地部署大模型。
- **重要功能指标**
  - 离线环境下支持视频生视频能力，基于原始视频进行风格重塑、内容编辑、效果优化，不依赖外部云服务。
  - 支持 MP4、MOV、AVI 等主流格式视频素材上传。
  - 可通过提示词定义更换风格、调整色调、添加动态元素、优化镜头节奏、替换背景等需求。
  - 最高生成 720P 分辨率、最长 5 秒的重塑后视频，并保留原始素材核心信息。
- **备注**
  - 需要甲方提供 API。

### 13. 多助手配置与管理

- **功能描述**
  - 支持自定义人设助手，实现多助手创建、配置、切换与生命周期管理。
- **重要功能指标**
  - 离线状态下内置 23 个 AI 实用小助手，覆盖多种 AI 设计场景。
- **备注**
  - 需要甲方提供 API。

## 三、文档要点提炼

- 平台定位为 **AI 多模态交互平台系统**，覆盖文本、图像、语音、视频等多种生成与理解能力。
- 方案同时考虑 **联网 API 调用** 与 **离线本地大模型部署** 两种运行模式。
- 管理能力较完整，覆盖账号体系、角色权限、用户分组、会话隔离、层级管理等。
- 知识库能力强调 **私有化、RAG、异构数据处理、联合检索、目录结构保持**。
- 多媒体生成能力的离线指标在文档中给出了较明确边界：
  - 图片生成最高 2K 分辨率；
  - 视频生成最高 720P；
  - 单次视频时长最长 5 秒。
- 文档多处注明 “**需要甲方提供 API**”，说明外部模型服务账户和相关费用主要由甲方负责。
